কিরন ক্রিয়েশান — Wedding Invitation Video Maker (Step 3: MP4)
============================================================

এই সংস্করণে কী আছে
- ৩টি wedding invitation template
- বর-কনের নাম, তারিখ, ভেন্যু, বার্তা ও ছবি দিয়ে প্রিভিউ
- ১০/১৫/২০ সেকেন্ডের animated vertical video
- Node.js + FFmpeg দিয়ে WebM রেকর্ডিংকে MP4-তে রূপান্তর
- MP4 ডাউনলোড

গুরুত্বপূর্ণ: এটি এখন আপনার নিজের Windows কম্পিউটারে চালানোর লোকাল সংস্করণ। এখনও অনলাইন ওয়েবসাইট, Login, Database, Payment Gateway বা Admin Panel যোগ হয়নি।

প্রথমবার চালানোর নিয়ম (Windows)
1. ZIP ফাইলের উপর Right-click > Extract All করুন।
2. Node.js LTS ইনস্টল না থাকলে https://nodejs.org থেকে LTS সংস্করণ ইনস্টল করুন। ইনস্টল শেষে কম্পিউটার/টার্মিনাল নতুন করে খুলুন।
3. ইন্টারনেট চালু রাখুন। ফোল্ডারের START_SERVER.bat-এ ডাবল-ক্লিক করুন। প্রথমবার npm package ডাউনলোড হতে কয়েক মিনিট লাগতে পারে।
4. Chrome-এ http://localhost:3000 খুলবে। না খুললে নিজে Chrome-এ এই ঠিকানা লিখুন।
5. টেমপ্লেট বাছুন, নাম/তারিখ/ভেন্যু লিখুন, চাইলে ছবি ও নিজের লাইসেন্সকৃত মিউজিক দিন।
6. ভিডিওর দৈর্ঘ্য বেছে “ভিডিও রেকর্ড শুরু” চাপুন। সময় শেষ হলে MP4 কনভার্ট হয়ে ডাউনলোড হবে।
7. কালো Command Prompt উইন্ডোটি বন্ধ করবেন না—এটি সার্ভার চালু রাখে। বন্ধ করলে সার্ভার থেমে যাবে।

সমস্যা হলে
- “node is not recognized”: Node.js LTS ইনস্টল করে START_SERVER.bat আবার চালান।
- প্রথমবার setup ব্যর্থ: ইন্টারনেট পরীক্ষা করে আবার START_SERVER.bat চালান।
- MP4 কনভার্ট না হলে: Command Prompt-এ যে error দেখায় সেটি কপি করে পাঠান।
- শুধু index.html-এ ডাবল-ক্লিক করলে MP4 সার্ভার চালু হবে না; START_SERVER.bat ব্যবহার করুন।

নিরাপত্তা ও সীমাবদ্ধতা
- সার্ভারটি শুধু আপনার কম্পিউটারের 127.0.0.1 ঠিকানায় চলে; এটি নিজে থেকে ইন্টারনেটে প্রকাশিত নয়।
- ২৫০ MB-এর বেশি আপলোড এই সংস্করণে গ্রহণ করা হবে না।
- কেবল নিজের বা লাইসেন্সকৃত ছবি/মিউজিক ব্যবহার করুন।
- পেমেন্ট চালু করতে হলে আলাদা নিরাপদ backend, merchant account এবং server-side payment verification প্রয়োজন।
